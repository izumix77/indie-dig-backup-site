Indie Dig Backup

A personal backup tool for the INDIE DIG project · 日本語

HomePrivacy Policy
In one sentence: Indie Dig Backup is a private app used by one person, its developer, to copy backups of the developer’s own INDIE DIG data into the developer’s own Google Drive and to check that those copies can be read back and restored. It is not offered to the public and has no other users.

What it is

INDIE DIG is a personal research project that collects publicly available information from the Steam store (for example game titles, prices, tags and review counts) and publishes derived datasets. Indie Dig Backup is the command-line component that creates a complete backup of that project’s database and files on the developer’s own computer and then sends the backup to the developer’s Google Drive, so that a copy exists away from the computer.

It has no web interface, no accounts, no advertising and no analytics. This website is public and is only a description of the app and its privacy policy; the app itself is for its owner only and cannot be used by visitors.

Google permission requested

The app requests exactly one Google OAuth scope:

https://www.googleapis.com/auth/drive.file

With this scope the app can only see and manage files and folders that it created itself. It cannot see any other file in the Google Drive. The app does not request access to Gmail, Contacts, Calendar, profile information or any other Google service.

How the permission is used

  • Create: create a backup folder in the owner’s Drive and upload backup files into it. Each backup is uploaded under a temporary name and is given its final name only after the upload is complete.
  • Retrieve: list the files the app created (names, sizes, checksums) and download them again.
  • Verify: compare what Drive reports and what is downloaded with the checksums recorded at backup time, and run restore tests on the owner’s own computer to prove that a backup is usable.

In its current version the app does not delete or overwrite existing backups, and it does not change sharing settings: backups stay private to the owner’s Google account. If the owner later has the app manage retention or remove old backups, that would be done only on the owner’s instruction and only to files the app created; this page would be updated if the way Google data is used changes.

What a backup contains

  • A dump of the INDIE DIG PostgreSQL database: public Steam store information about games and its observations over time, run and error records of the collectors, event records and publication records.
  • Raw collected responses (compressed copies of public Steam store responses), published dataset files and internal export files.
  • A manifest, file inventory and checksums used for verification.

Backups do not contain passwords, API keys, OAuth credentials, or the private configuration files of the computer. They contain no data about other Google users and no data from the owner’s Drive other than the backups themselves.

Where credentials are kept

The OAuth client ID, client secret and the access/refresh tokens are kept in one private configuration file on the owner’s computer, outside the source-code repository, readable only by the user account that runs the backup (file mode 0600, in a directory that only that account can open). They are entered without being displayed, are never committed to source control, and are never written to logs or shown in output. The app does not send them to anyone other than Google.

Selling and sharing

The developer does not sell, rent, share or transfer any data obtained through Google APIs to any third party, and does not use it for advertising or to train machine-learning models. The backups are read only by the owner’s own software. Details are in the Privacy Policy.

Revoking access

The owner can withdraw the app’s access at any time in the Google Account: myaccount.google.com/permissions → choose the app → Delete all connections. Revoking access does not delete the backup files already in Drive; they can be removed from Drive like any other file.

Indie Dig Backup（日本語）

概要： Indie Dig Backup は、開発者本人だけが使う、INDIE DIG プロジェクトのバックアップ用アプリです。開発者自身のデータのバックアップを、開発者自身の Google ドライブに保存し、保存したものを読み戻して復元できることを確認します。一般公開はしておらず、他の利用者はいません。

このアプリについて

INDIE DIG は、Steam ストアで公開されている情報（タイトル、価格、タグ、レビュー件数など）を集め、派生データセットを公開する個人の調査プロジェクトです。Indie Dig Backup は、そのデータベースとファイルの完全なバックアップを手元のコンピュータで作り、開発者の Google ドライブへ送るコマンドライン部品です。画面、アカウント、広告、アクセス解析はありません。このサイトは一般公開で、アプリの説明とプライバシーポリシーのためだけにあります。アプリ自体は本人専用で、サイトの訪問者が使うことはできません。

要求する Google の権限

OAuth スコープは https://www.googleapis.com/auth/drive.file の1つだけです。このスコープでは、アプリ自身が作成したファイルとフォルダしか扱えません。ドライブ内のそれ以外のファイルは見えません。Gmail、連絡先、カレンダー、プロフィール情報などは要求しません。

権限の使い方

  • 作成： ドライブにバックアップ用フォルダを作り、バックアップファイルをアップロードします。一時的な名前でアップロードし、完了後に正式な名前にします。
  • 取得： アプリが作成したファイルの一覧（名前・サイズ・チェックサム）を取得し、再ダウンロードします。
  • 検証： ドライブの報告やダウンロード結果を、バックアップ時に記録したチェックサムと照合し、手元で復元テストを行います。

現在の版では、既存のバックアップの削除・上書きや共有設定の変更はしません。バックアップは本人の Google アカウント内に非公開のまま保存されます。将来、所有者の指示で保存期間の管理や古いバックアップの削除を行う場合も、本アプリが作成したファイルに限り、所有者の指示によってのみ行います。Google データの使い方が変わる場合は、このページを更新します。

バックアップに含まれるデータ

  • INDIE DIG の PostgreSQL データベースのダンプ：Steam ストアの公開情報（ゲームの情報と時系列の観測値）、収集ジョブの実行・エラー記録、イベント記録、公開記録。
  • 収集した生データ（Steam ストアの公開レスポンスの圧縮コピー）、公開データセットのファイル、内部エクスポートファイル。
  • 検証用のマニフェスト、ファイル一覧、チェックサム。

パスワード、API キー、OAuth 認証情報、コンピュータの非公開設定ファイルは含まれません。他の Google ユーザーのデータや、バックアップ以外のドライブ内データも含まれません。

認証情報の保管

OAuth クライアント ID・シークレットとトークンは、開発者のコンピュータ上の1つの非公開設定ファイルに保管します。ソースコードのリポジトリの外にあり、バックアップを実行するユーザーアカウントだけが読めます（ファイルモード 0600、そのアカウントだけが開けるディレクトリ内）。入力時は画面に表示されず、ソース管理へのコミット、ログへの出力、画面表示は行いません。Google 以外には送信しません。

販売・提供

Google API を通じて得たデータを、第三者に販売・貸与・共有・提供することはありません。広告や機械学習モデルの学習にも使いません。詳細はプライバシーポリシーをご覧ください。

アクセスの取り消し

Google アカウントの myaccount.google.com/permissions でアプリを選び「すべての接続を削除」を選ぶと、いつでもアクセスを取り消せます。取り消しても、すでにドライブにあるバックアップファイルは削除されません。ほかのファイルと同様にドライブから削除できます。
