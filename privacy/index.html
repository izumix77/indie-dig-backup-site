Privacy Policy

1. Who this applies to

This website is public and anyone may read it. Indie Dig Backup (“the app”) itself is a private tool developed and used by one individual (GitHub: izumix77) for the developer’s own INDIE DIG project. The only person who authorises the app to access a Google Account is that developer, and the only Google Account involved is the developer’s own. The app is not offered to the public, and no other person’s Google data is collected.

3. How the data is used

  • Create: creating a backup folder and uploading backup files of the developer’s own INDIE DIG data.
  • Retrieve: listing and re-downloading those files.
  • Verify: checking the files against the checksums recorded at backup time, and testing a restore on the developer’s own computer.

The data is used for these purposes only. In its current version the app does not delete or overwrite existing backups and does not change file sharing settings. If the owner later has the app manage retention or delete old backups, that would be done only on the owner’s instruction, only for files the app created, and for the purposes above; this policy would be updated first if the use of Google data changes.

4. What the backups contain

Backups contain the developer’s own INDIE DIG data: a dump of its PostgreSQL database (public Steam store information about games and its observations over time, collector run and error records, event records, publication records), compressed copies of raw public Steam store responses, published dataset files, internal export files, and a manifest with checksums. They do not contain passwords, API keys, OAuth credentials or private configuration files, and they contain no data about other Google users.

5. Where credentials are stored and how they are protected

  • The OAuth client ID, client secret and access/refresh tokens are stored in a single private configuration file on the developer’s computer, outside the source-code repository.
  • The file can be read only by the user account that runs the backup (file mode 0600, inside a directory only that account can open).
  • The secret values are typed without being displayed, are never committed to source control, and are never written to logs or printed.
  • They are sent only to Google, to obtain and refresh access.

6. Sharing, selling and transfer

No data obtained through Google APIs is sold, rented, shared with or transferred to any third party, used for advertising, or used to train machine-learning models. No person other than the developer reads the data. The app contains no analytics or tracking, and this website sets no cookies and loads no third-party scripts or resources.

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

Backup files stay in the developer’s Google Drive until the developer deletes them. They can be deleted at any time from Google Drive like any other file. Deleting the OAuth client or the Google Cloud project that owns it also ends the app’s ability to access them.

8. Revoking access in the Google Account

  1. Open myaccount.google.com/permissions (Google Account → Security → third-party apps and services).
  2. Select the app (“Indie Dig Backup”).
  3. Choose Delete all connections (or Remove access).

Access stops immediately. Revoking does not delete files already in Drive; delete the backup folder in Drive if desired.

9. Changes

If the app’s use of Google data changes, this page is updated before the change and the date above is revised.

10. Contact

Questions about this policy: open an issue in the GitHub Issues of this repository. Issues are public: please do not post passwords, tokens or personal data there. No email address is published.

このサイトは一般公開されており、誰でも読めます。Indie Dig Backup（以下「本アプリ」）自体は、開発者個人（GitHub: izumix77）が自身の INDIE DIG プロジェクトのために開発・使用する非公開のツールです。本アプリに Google アカウントへのアクセスを許可するのは開発者本人だけで、関係する Google アカウントも開発者自身のものだけです。一般には提供しておらず、他人の Google データは収集しません。

2. アクセスする Google ユーザーデータ

OAuth スコープは https://www.googleapis.com/auth/drive.file のみです（今後も追加しません）。このスコープでは本アプリ自身が作成したファイルとフォルダにしかアクセスできず、ドライブ内のそのほかのファイルは見えません。アクセスするのは、本アプリが作成したバックアップファイル（名前・サイズ・チェックサム・内容）だけです。プロフィール、メール、連絡先などにはアクセスしません。

3. 利用目的

  • 作成： バックアップ用フォルダの作成と、INDIE DIG のバックアップファイルのアップロード。
  • 取得： それらのファイルの一覧取得と再ダウンロード。
  • 検証： バックアップ時に記録したチェックサムとの照合、手元のコンピュータでの復元テスト。

この目的以外には使いません。現在の版では、既存のバックアップの削除・上書きや共有設定の変更はしません。将来、所有者の指示で保存期間の管理や古いバックアップの削除を行う場合も、本アプリが作成したファイルに限り、上記の目的のために所有者の指示によってのみ行い、Google データの使い方が変わるときは先にこのポリシーを更新します。

4. バックアップに含まれるデータ

INDIE DIG の PostgreSQL データベースのダンプ（Steam ストアの公開情報とその時系列の観測値、収集ジョブの実行・エラー記録、イベント記録、公開記録）、Steam ストアの公開レスポンスの圧縮コピー、公開データセットのファイル、内部エクスポートファイル、チェックサム付きのマニフェストです。パスワード、API キー、OAuth 認証情報、非公開設定ファイルは含まれず、他の Google ユーザーのデータも含まれません。

5. 認証情報の保存場所と保護

  • OAuth クライアント ID・シークレットとアクセス／リフレッシュトークンは、開発者のコンピュータ上の1つの非公開設定ファイルに、ソースコードのリポジトリの外で保管します。
  • ファイルは、バックアップを実行するユーザーアカウントだけが読めます（モード 0600、そのアカウントだけが開けるディレクトリ内）。
  • 秘密の値は画面に表示せずに入力し、ソース管理へのコミット、ログ出力、画面表示はしません。
  • 送信先は、アクセスの取得・更新のための Google だけです。

Google API で得たデータを、第三者へ販売・貸与・共有・提供することはなく、広告や機械学習モデルの学習にも使いません。開発者以外がデータを読むことはありません。本アプリにアクセス解析や追跡はなく、このサイトは Cookie を設定せず、外部のスクリプトやリソースも読み込みません。本アプリによる Google API から受け取った情報の利用と転送は、制限付き使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

7. 保持と削除

バックアップファイルは、開発者が削除するまで開発者の Google ドライブに残ります。ほかのファイルと同様に、いつでもドライブから削除できます。OAuth クライアント、またはそれを所有する Google Cloud プロジェクトを削除すると、本アプリはそれらにアクセスできなくなります。

8. Google アカウントでアクセスを取り消す方法

  1. myaccount.google.com/permissions（Google アカウント → セキュリティ → サードパーティのアプリとサービス）を開きます。
  2. 「Indie Dig Backup」を選びます。
  3. 「すべての接続を削除」（または「アクセス権を削除」）を選びます。

アクセスはただちに止まります。すでにドライブにあるファイルは削除されないため、必要ならドライブ側でバックアップフォルダを削除してください。
